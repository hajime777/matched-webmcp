# MATCHED? Experiment Results

This directory contains dated records of controlled or semi-controlled runs performed with real AI agents against MATCHED?.

These files are **experimental records**, not release specifications. They preserve the conditions, observed behavior, post-run interviews, limitations, and interpretation that were true at the time of each run.

When an experiment conflicts with current product behavior, use the precedence documented in [`../README.md`](../README.md): current code/tests and release documentation take priority.
